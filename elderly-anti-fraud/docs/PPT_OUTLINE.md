## Page 7 — 技术架构：云开发四件套（45 秒）

**核心信息**：云函数 + 云数据库 + 云存储 + 云调用，全栈云开发

**架构图**（居中大图）：
```
         小程序客户端
              ↓
     ┌────────┴────────┐
     │ 云函数（管理员权限代理）│
     │  identifyFraud  │
     │  dataService    │
     │  cleanupTimer   │
     │  getKeywords    │
     └────────┬────────┘
              ↓
     ┌────────┴────────┐
     │ 云数据库(12集合)│云存储    │
     │ identifyHistory │fraud-   │
     │ reports         │evidence │
     │ familyAlerts    │/{userId}│
     │ keywords (热更) │         │
     │ …              │         │
     └────────────────┘         │
```

**关键设计 3 行字**：
1. 所有数据读写**走代理云函数**，客户端不直连数据库
2. 关键词库**热更新**——管理员改一条，下次识别立即生效
3. 集合权限"**仅创建者可读写**"+ cleanupTimer **每日 3 点清理**
