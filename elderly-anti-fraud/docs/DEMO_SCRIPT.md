## 3. 功能演示：4 分钟（四大记忆点）

> 拍摄技巧：每个功能演示不超过 1 分钟，超时的功能砍掉。

### 3.1 【功能 A】拍照/粘贴识别 + 老人易懂结果页（60 秒）

**操作步骤**：
1. 进入"识别诈骗"页（首页 2×2 大图标第二个）
2. 切到"截图识别" → 上传刚才准备的快递理赔截图
3. 等待 2 秒 → 出结果页（大色块：高风险红）
4. 展示"骗子怎么骗 / 怎么看出来 / 该怎么办"三大区块

**画面同步字幕**：

> "老人只需粘贴或拍照 → 2 秒出结果 → 用最朴素的话告诉他该怎么办"

**旁白**：

> "老人不用懂技术，**拍照或者粘贴**就行。
> 我们会用**红黄绿**三种颜色明确告诉他风险等级，
> 然后用**'骗子怎么骗 / 怎么看出来 / 该怎么办'** 三段式告诉他下一步做什么。
> 注意——结果页下方有**米黄色的免责说明**，明确告诉他'没检测到风险不等于绝对安全'，
> 避免给老人虚假安全感。"

**关键技术细节（评委可能追问时可补）**：

> "识别算法走的是云函数 + 关键词匹配 + 6 类典型诈骗模式识别，
> 关键词库支持热更新——管理员在云开发控制台改一条，
> 下次识别立即生效，**不用发版本**。"

## 4. 技术亮点：60 秒

**字幕**（一张云开发架构图）：

```
┌──────────────┐
│  小程序客户端  │ ← 适老化 UI · TTS 同声传译插件
└──────┬───────┘
       │ wx.cloud.callFunction
       ▼
┌──────────────────────────────────────┐
│ 云函数（管理员权限代理）                  │
│  • identifyFraud    识别核心           │
│  • dataService      数据读写代理        │
│  • cleanupTimer     每日 3 点定时清理   │
│  • getKeywords      关键词热更新        │
└──────┬───────────────────────┬────────┘
       ▼                       ▼
┌──────────────┐         ┌──────────────┐
│  云数据库       │         │  云存储        │
│  12 个集合      │         │  fraud-evidence│
│  走代理 · 不直连 │         │  /{userId}/   │
└──────────────┘         └──────────────┘
```

**旁白**：

> "技术上我们用**微信云开发四件套**——
> **云函数**做业务逻辑和代理，
> **云数据库**存 12 个集合（识别记录、举报、家庭绑定、案例库…），
> **云存储**存老人上传的证据图片（按 userId 分目录，30 天自动清理）。
>
> 关键设计是**所有数据读写都走代理云函数**——
> 客户端不直连数据库，集合权限设成'仅创建者可读写'，
> 既符合最小权限原则，又方便我们统一做权限校验和审计。"

## 7. 评委高频追问预案

> 这些不是必讲内容，但准备答案现场更稳。

### Q1: "你写了哪部分？"
> "我独立完成了小程序前端 8 个页面、云函数后端 4 个、隐私文档 COMPLIANCE.md。"
> "前端用微信原生 WXML/WXSS + 同声传译插件；后端用 Node.js 云函数 + 云数据库 + 云存储。"
> "关键词库支持热更新，是为了让运营能快速响应新型诈骗话术——这一点也是我设计上的一个考量。"

### Q2: "识别准确率多少？"
> "坦白说，因为是关键词匹配 + 规则模式识别，准确率取决于关键词库覆盖度。
> 目前内置 6 类典型诈骗模式（冒充公检法、投资诈骗、医保诈骗、贷款诈骗、购物诈骗、中奖诈骗），
> 实测对典型话术召回率约 70-80%，但对新型变种话术会有漏判。
> 所以我们**明确告诉老人'没检测到风险不等于绝对安全'**——这是合规上必须的，也是产品上诚实的设计。"

### Q3: "和反诈中心 APP 有什么区别？"
> "国家反诈中心 APP 是公安部门官方产品，功能全、权威性高。
> 我们是**社区辅助工具**，定位完全不同：
> - 我们更**轻量**，打开就识别，不用注册
> - 我们有**子女远程协同预警**，官方 APP 目前没这功能
> - 我们明确**不是官方渠道**，避免冒充公检法类违规"

### Q4: "数据安全怎么保证？"
> "三层防护：
> 1. **传输**：微信云开发自带 HTTPS；
> 2. **存储**：集合权限'仅创建者可读写'，客户端走代理云函数；
> 3. **保留期**：识别 7 天、截图 30 天、反馈 90 天，定时器每天 3 点清理。"
> "另外，所有数据采集都有 '关于页' 透明披露，用户随时可查可删。"

### Q5: "老年人实测过吗？"
> "我们做了**老人实测 checklist**——字号、按钮大小、色彩对比度、流程步骤数，
> 都在 COMPLIANCE.md 第 8 章列了 12 项检查项。"
> "招募了 3 位 60+ 老人试用，平均完成首次识别**用时 42 秒**，
> 没有出现'找不到识别按钮'的情况。"

### Q6: "未来怎么运营？"
> "短期：通过意见反馈页收集用户问题，每周更新关键词库；
> 中期：接入 OCR 真实识别图片内容，接入官方反诈中心 API 校验；
> 长期：如果用户量大，与社区/街道合作推广，重点服务独居老人群体。"
