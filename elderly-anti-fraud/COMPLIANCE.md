# 合规与边界说明（COMPLIANCE.md）

> 本文档说明本工具的合规边界、隐私政策要点、数据库权限模型及免责声明，供产品上线、答辩、第三方审计使用。

---

## 一、产品定位（最重要）

| 项目 | 说明 |
|---|---|
| **本工具是什么** | 社区互助型辅助应用，帮助老人识别可疑信息、学习防诈知识、联系家人守护 |
| **本工具不是什么** | ❌ 不是国家反诈中心 / ❌ 不是公安机关 / ❌ 不是银行 / ❌ 不是任何官方机构 |
| **能力范围** | 关键词匹配型识别（仅供参考）、案例知识科普、家庭守护、举报线索记录、外线电话引导 |
| **能力边界** | 不能直接对接反诈中心、不能代替报警、不能保证识别结果 100% 准确 |

📌 必须在产品显著位置（首页、关于页、拨号弹窗）写明"非官方应用，紧急情况请拨打 110 或 96110"。

## 二、合规红线（务必避免）

### 2.1 命名与宣传

- ❌ 不得自称"官方反诈中心""警方渠道""认证应用"等
- ❌ 不得使用警徽、国徽、警旗等国家机关标志
- ❌ 不得使用与反诈中心、公安部相同或近似的名称
- ✅ 我们的产品名就叫"防诈骗互助"，副标题明确"社区辅助工具"

### 2.2 功能边界

- ❌ 不做代客转账、资金操作类功能（违规且高风险）
- ❌ 不接入真实银行接口、不调用支付 API
- ❌ 不向第三方共享用户数据
- ✅ 我们的功能全部限于"识别+科普+本地守护"，不涉及资金流

### 2.3 平台合规（个人主体）

| 类目 | 是否涉及 | 备注 |
|---|---|---|
| 金融 | ❌ | 我们没有支付、信贷、理财功能 |
| 安全 | ❌ | 我们不是杀毒软件、不是密码管理 |
| 医疗 | ❌ | 没有健康相关功能 |
| 工具 → 信息查询 | ✅ | 这是我们当前的类目方向 |
| 社交 → 论坛/社区 | ✅ | 求助社区的类目 |

📌 **建议在发布前登录微信公众平台 → 设置 → 基本设置 → 服务类目，确认当前类目设置正确**。个人主体某些受限类目需要补充资质，我们已经规避。

## 三、隐私政策要点

### 3.1 我们收集的数据

| 数据 | 收集方式 | 用途 | 存储 |
|---|---|---|---|
| 匿名 userId | 自动生成 | 区分不同用户的记录 | 本地 + 云端 |
| 自定义称呼 | 用户主动输入 | 个人中心显示 | 本地 + 云端 |
| 6 位家庭守护码 | 自动生成 | 家庭绑定配对 | 仅本机 |
| 子女称呼+电话 | 用户主动录入 | 一键呼叫（紧急联系） | 仅本机 |
| 识别内容 | 用户主动输入/上传 | 风险识别 | 提交后存入云端 |
| 举报线索 | 用户主动提交 | 举报记录 | 云端 |

### 3.2 我们不收集的数据

- ❌ 真实姓名 / 身份证号 / 银行卡号
- ❌ 通讯录 / 短信 / 通话记录
- ❌ 地理位置（已关闭定位权限）
- ❌ 微信好友关系 / 群信息

### 3.3 第三方共享

**本工具不向任何第三方共享用户数据**。包括但不限于：
- 不接入广告 SDK
- 不接入用户画像系统
- 不接入第三方统计分析（如需统计仅在云函数内做）

### 3.4 数据保留与删除

- 识别记录、举报记录：用户可在"我的 → 识别历史"一键清空
- 家庭成员信息：解除绑定立即清除
- 子女紧急电话：仅本机，长按即可编辑/删除
- 账户注销功能：当前为简化版（清空 storage + 清空云端数据），后续可加

### 3.5 用户权利

- 知情权：本页面已说明所有数据用途
- 访问权："我的"页面可查看所有记录
- 更正权：称呼、子女电话均可修改
- 删除权：一键清空 / 解除绑定 / 退出小程序
- 撤回权：识别结果不强制保存

### 3.6 适用法律

- 《中华人民共和国个人信息保护法》（PIPL）
- 《中华人民共和国网络安全法》
- 《中华人民共和国数据安全法》
- 《信息安全技术 个人信息安全规范》GB/T 35273

## 四、数据库权限模型

### 4.1 设计原则

> **客户端不直接连数据库。所有读写统一走 `dataService` 云函数（管理员权限）。**

这是因为：
- 微信云开发集合权限默认是"仅创建者可读写"，客户端读不到其他用户创建的共享数据
- 直接给客户端管理员权限会暴露所有用户隐私
- 走云函数代理既绕过了权限问题，又保护了数据安全

### 4.2 集合权限设置

所有 6 个集合均保持微信云开发默认权限：**仅创建者可读写**。

| 集合 | 用途 | 权限 |
|---|---|---|
| `fraudCases` | 案例库（共享阅读） | 仅创建者可读写 + 云函数代理读 |
| `alerts` | 预警信息（共享阅读） | 仅创建者可读写 + 云函数代理读 |
| `communityPosts` | 社区帖子（含回复） | 仅创建者可读写 |
| `reports` | 举报记录 | 仅创建者可读写 |
| `identifyHistory` | 识别历史 | 仅创建者可读写 |
| `users` | 用户信息 | 仅创建者可读写 |

### 4.3 云函数架构

```
┌─────────────────┐   wx.cloud.callFunction    ┌──────────────────┐
│   小程序客户端   │  ──────────────────────►   │  dataService 云函数│
│  (无 db API)    │   { action: 'getXxx' }     │  (管理员权限)     │
└─────────────────┘                             └────────┬─────────┘
                                                         │
                                                db.collection('xxx')
                                                         │
                                                ┌────────▼─────────┐
                                                │  云数据库（受限）  │
                                                └──────────────────┘
```

### 4.4 云函数当前支持的操作

`dataService` 云函数包含 16 个 action：

- `getCases` / `getAlerts` / `getPosts` —— 读共享数据
- `createPost` / `replyPost` / `likePost` / `removeReply` —— 社区互动
- `addReport` / `getReports` / `deleteReport` —— 举报
- `saveHistory` / `getHistory` / `getStats` / `deleteHistory` / `clearHistory` —— 识别历史
- `getRecentIdentify` —— 家庭守护动态

每个 action 内部都做了：
- 参数校验
- 长度限制（防注入）
- 错误处理
- 业务校验（如 `addReport` 校验 type/phone/desc 必填）

## 五、关键内容安全

### 5.1 UGC 内容

社区帖子、举报描述属于用户生成内容（UGC），必须做：
- ✅ 长度限制（500/1000 字以内）
- ✅ 关键词过滤（识别"高敏感"内容）
- ✅ 举报机制（用户可举报，社区自治）
- ⚠️ 后续可加：人工审核 / 敏感词库 / 屏蔽机制

### 5.2 知识库

- 内容来源：公开的反诈案例和新闻（已注明）
- 不杜撰"权威发布"
- 不使用"公安部""国家反诈中心"等机构名义发布
- 引导用户拨打外线电话（110、96110）核实

## 六、风险免责

### 6.1 识别功能免责

- 识别结果基于关键词匹配，**仅供参考**
- 不能作为判定诈骗的唯一依据
- 复杂诈骗（情感诱导、AI 换脸）可能识别不出
- 最终判断请以"打 96110 核实"为准

### 6.2 家庭守护功能免责

- 本工具的家庭绑定基于匿名 6 位码，**不能保证绝对安全**
- 守护码一旦泄露，他人可冒充家人绑定
- 建议定期更换守护码（功能已提供）
- 紧急情况请优先拨打 110/96110，不要只依赖本应用

### 6.3 第三方服务免责

- 同声传译插件（WechatSI）由微信提供，本应用不存储朗读内容
- 云开发能力由微信云提供，遵循微信云服务协议

### 6.4 不可抗力

- 网络故障 / 云服务中断期间，识别、举报、家庭守护可能不可用
- 建议老人同时保存社区民警、银行客服电话作为备用

## 七、用户体验设计（适老化）

| 设计点 | 实现方式 |
|---|---|
| 大字号 | 全局基础字号 32rpx（最大 38rpx），"大字模式"开关 |
| 大按钮 | 按钮触控区 ≥ 88rpx，文字 ≥ 28rpx |
| 高对比 | 主文字 #1a1a1a，背景 #fff，避免浅灰对浅灰 |
| 大色块 | 风险等级用 绿/黄/红 一眼可辨 |
| 简化文案 | "骗子是怎么骗的""您应该这样做"代替术语 |
| 语音播报 | 接入同声传译插件，一键朗读识别结果 |
| 拍照存证 | 选图后自动加密上传到云存储 |
| 一键呼叫 | 老人端预设子女电话，大按钮直接拨号 |
| 紧急热线 | 110、96110 暴露在多个页面顶部 |
